# Types of Cloud Storage

| Storage Type | Description | Primary Use Case | Cloud Provider Example |
|---|---|---|---|
| Block Storage | Stores data in fixed-size blocks that can be accessed individually. | Virtual machines and databases | AWS EBS |
| File Storage | Stores data as files organized into folders and directories. | Shared files and applications | AWS EFS |
| Object Storage | Stores data as objects together with metadata and a unique identifier. | Images, videos, backups, and other unstructured data | Amazon S3 |

## Why Object Storage?

Object Storage is a good choice for the client's photo-sharing application because it is designed for storing large amounts of unstructured data such as images. It can also provide scalable and accessible storage for millions of uploaded photos.
