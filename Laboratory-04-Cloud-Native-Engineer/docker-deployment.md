## Container Lifecycle

| Command                | Explanation                                                                  |
| ---------------------- | ---------------------------------------------------------------------------- |
| `docker ps`            | Lists the containers that are currently running.                             |
| `docker stop my-nginx` | Stops the running Nginx container named `my-nginx`.                          |
| `docker ps `         | Displays all containers, including stopped containers, to verify its status. |
| `docker rm my-nginx`   | Removes the stopped `my-nginx` container completely.                         |
